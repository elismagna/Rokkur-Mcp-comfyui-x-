Agents

Three agents use a language model: the Creative Director writes each video's brief and what every shot shows, the Director of Photography picks each shot's framing and lighting from the allowed terms, and the Channel Manager writes the title, description and tags. If the model is unavailable they fall back to built-in rules, so a render never waits on it.
