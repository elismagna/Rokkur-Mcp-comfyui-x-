Prompt rules

Rule of Nouns
Framing and nouns first: prefix, shot size, angle, movement, subject, lighting, background, theme, global style. The subject is one unbroken block: the character's description, then the shot's pose and expression, with commas only.
Action strip-out
Story phrasing becomes physical states: "is walking" → in mid-stride, "suddenly runs" → in full sprint, "thinking about home" → focused expression.
Token weights
Shot size × {{ d.framing_weight }}, camera angle × {{ d.angle_weight }}, e.g. (close-up shot:{{ d.framing_weight }}). Brackets and weights inside agent or user text are removed.
Prompt schedule
A keyframe every {{ d.schedule_interval }} frames at {{ d.schedule_fps }} fps, plus one on each side of every cut so cuts stay hard{% if d.schedule_inline_negative %}; negatives after --neg{% endif %}. Each video's page has it ready to copy into FizzNodes' Batch Prompt Schedule.
